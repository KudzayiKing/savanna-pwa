### Gotchas learned (added to skill `animate-raster-logo-parts`)
1. **FATAL**: a CSS comment inside an SVG `<style>` containing a literal
   `<...>` (e.g. `<svg>`, `<path>`) makes Chrome close `<style>` early,
   silently dropping `@keyframes`/`animation`. Symptom:
   `document.getAnimations().length === 0`, `animationDuration === "0s"` while
   `fill` renders fine. Fix: plain-prose comments, no angle brackets.
2. Freezing animation frames: `animation-play-state:paused` + `animation-delay`
   injection does NOT seek frames inside inline/`img` SVG. Use
   `document.getAnimations().forEach(a=>{a.currentTime=X; a.pause();})` after
   inlining the SVG into the page.
3. `pngtool.encode_png(w, h, rgba_bytes)` — arg order `(w, h, rgba)`, not
   `(rgba, w, h)`.
4. Marching-squares + RDP for ragged/non-circular raster shapes; single clean
   `key=(round(x*2),round(y*2))` adjacency, plus a bbox-sanity assert.
5. PWA icon-regen-on-dark-tile + rail-icon framing-match workflow (Step 8b).

### Gotchas learned (added to skill `animate-raster-logo-parts`)
6. **Transparent-bg logo: you can't "cover" with a bg colour.** Mask the
   target pixels to transparent in the base raster (body-only) and overlay the
   traced vector. Dilate the mask 1px so the overlay fully covers the original.
7. **FATAL re-run trap:** a build/trace script that writes its OUTPUT to the
   same path as the SOURCE overwrites (and destroys) the user's original. This
   session overwrote `savanna_megaphone_vector.svg` on run 1; recovered from
   `dist/public/` copy. Always pin `SRC` to a read-only copy (e.g. `/tmp`) and
   write outputs to `client/public/`.
