## Made Stories SquarePlayIcon animate like the other mobile nav icons

- The other bottom-nav icons in `AnimatedNavIcons.tsx` are `state`-driven: `MobileNavIcon` computes `state = "idle" | "active"` and, on touch devices, flips to `"active"` only AFTER `MOBILE_NAV_ICON_ACTIVE_PILL_DELAY_MS` (the pill slide-in) via `scheduleMobilePressAnimation()` (triggered by `onTouchStart`/`onPointerDown` + the `becameActive` effect). On desktop it flips on `onPointerEnter` (hover). Icons use `animate={state}` with `idle`/`active` variants.
- The Stories `SquarePlayIcon` I added was only hover-triggered via its own internal `useAnimation` + `onMouseEnter`, AND the `Stories` branch didn't forward `iconInteraction`, so on mobile it never animated at all.
- Fix: rewrote `SquarePlayIcon` to be `state`-driven — added a `state?: "idle" | "active"` prop, renamed variants `normal`/`animate` → `idle`/`active`, parent `m.svg` does `animate={motionState}` (`motionState = reduced ? "idle" : state`), removed the internal `useAnimation`/`useImperativeHandle`/`handleEnter`/`handleLeave`/`SquarePlayIconHandle` (those imports stay — used by the other icons). Stories branch now `return <SquarePlayIcon size={size} state={state} {...iconInteraction} />;`.
